# LgpdVendors

Filament plugin for laravel-lgpd-vendors: keep your LGPD vendor register in the panel, with DPA checklist, international transfers, reviews by risk tier and the issues each vendor still owes.

## Installation

You can install the package via composer:

```bash
composer require jeffersongoncalves/filament-lgpd-vendors
```
